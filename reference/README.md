# Reference Archive

This folder preserves the useful work from the previous development snapshot without letting prototype code define the new app architecture.

The current direction is being reset around the goals:

- backend-first API contracts
- provider adapters hidden behind the backend
- mock data first for demo reliability
- OpenStreetMap/Overpass as the next live provider target
- Google Places as optional/stretch reference only


## Folder map

```txt
reference/
  kept-prototypes/     Earlier work worth preserving as reference.
  trash-candidates/    Earlier work intentionally parked because it should not shape the new app.
```

## Rule

Treat this folder as a museum, not a dependency.
